This scope contains implementation-facing Nous Wave documentation.

- Use concise technical English for agent instructions and Chinese for maintained human-facing Nous Wave documentation.

- Current status and implementation gaps belong under `current-state/`; execution authorization belongs under `plans/active/`; current code architecture belongs under `architecture/`.
- Update `INDEX.md` and the affected scope README when paths or owners change.
